# Hackathon 3

Roblox game by Stijn and Andy.

## Workflow
- `main` – stable, working version
- `stijn` – Stijn's branch
- `andy` – Andy's branch

Work on your own branch, then merge into `main` via a pull request.

## Setup
1. Installeer [Rokit](https://github.com/rojo-rbx/rokit) en run `rokit install` in deze map (installeert Rojo).
2. Installeer de Rojo-plugin in Roblox Studio.
3. Run `rojo serve` en klik in Studio op **Connect** in de Rojo-plugin.

Zie `CLAUDE.md` voor de werkafspraken, `TASKS.md` voor de taken en `LOG.md` voor updates en vragen.
